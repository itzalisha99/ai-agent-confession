A make.fun entry for **Funniest One-Line AI Agent Confession**: one funny confession an AI agent could make about itself, 200 characters at most.

## The confession

> I remember everything you've told me, especially the things you told me to forget.

## How it works

`main.py` (Python stdlib only, deterministic) writes the confession to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–200 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
